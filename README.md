# Presupuesto Familiar GonGar

Interfaz web minimalista y 100% intuitiva para registrar ingresos quincenales, bonos y gastos familiares desde el teléfono, lista para desplegar en Vercel.

## Características
- **Gráfico Mensual Automático:** Comparativa mensual de Ingresos vs. Gastos en tiempo real mediante `Chart.js`.
- **Sueldos Quincenales y Bonos:** Entrada de sueldos y bonificaciones con selector de fecha para reflejar de inmediato cómo evoluciona tu flujo de efectivo mes a mes.
- **Gastos con Categoría y Vendor:** Registro rápido de salidas con comercio/vendor opcional.

## Despliegue en Vercel (en 2 pasos)
1. Sube esta carpeta/repositorio a **GitHub**.
2. Entra en [Vercel](https://vercel.com/), haz clic en **New Project**, selecciona el repositorio y presiona **Deploy**. 

Vercel detectará el archivo `vercel.json` y desplegará la aplicación FastAPI de forma automática.
